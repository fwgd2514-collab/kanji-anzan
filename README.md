# のびる｜漢字と暗算

GitHub Pagesへそのままアップロードできる静的Webアプリです。
インストールやビルドは不要です。

## 主な機能

- 学習する人の名前を登録
- 起動時に前回の学習者を大きく表示し、同じ人なら名前を選び直さず「この人で続ける」だけで開始
- 別の人が使う場合は、起動画面の名簿から名前を選び直して誤記録を防止
- 名前選択画面にアプリの最終更新日を表示
- 名前選択画面とホーム上部の「最新版に更新」から、iPhoneの古い表示を避けて最新ファイルを再読込
- 漢字を選ぶ、漢字を読む、暗算、フラッシュ暗算、フラッシュカード、数字記憶の6コース
- 文部科学省の現行学年別漢字配当表に沿い、小学校1〜6年の全1,026字を収録
- 中学校では小学校配当外の常用漢字1,110字を、使用頻度を参考に中1〜中3へ段階配置
- 学年別漢字一覧の文字をタップすると、読み方・ことば・活用事例・一画ずつの書き順を学習
- 中学3年より上に、難関四字熟語で使われる277字を集めた「お受験・発展漢字」一覧を追加
- Lv.1〜96は現在の学年の漢字を約8割、直前範囲の復習を約2割出題
- 同じ学年内でもレベルが上がるほど出題漢字が増え、後半では熟語問題の割合も上昇
- 「漢字を選ぶ」は、初めは読みから漢字を選び、学年後半では熟語の穴埋めへ発展
- 「漢字を読む」は、単漢字から熟語へ段階的に難しくなる4択問題
- Lv.97〜120は高校入試・大学・天才レベルとして、四字熟語400語を使う難問を出題
- 1回の学習では同じ漢字・同じ問題を重ねず、名前ごとの直近160字を避けて出題
- 「漢字を読む」「漢字を選ぶ」は、回答後に熟語の短い意味を表示
- 回答後は熟語内の漢字を選び、「書き順」を一画ずつ確認可能
- 漢字の読み方候補は問題ごとに並び替え
- フラッシュ暗算は減っていく横バーで開始を案内
- 同じ数字が続く場合も「＋」表示で切り替わりを確認
- `names.txt` から学習する人を選択し、名前ごとにレベルを保存
- 6コースのレベルとXPをそれぞれ個別管理
- 分野別レベル調整を開く時に保護者用パスワードを確認（初期値 `1234`）
- パスワード入力欄を押しても確認画面が閉じないよう、背景タップとの判定を分離
- 登録されている全員の6分野レベル一覧を表示
- Firebase設定後は、名前ごとの6分野レベル・XPを別端末と共有
- 正解・レベル変更後にFirebaseへ自動保存し、最終同期時刻を表示
- 選んだ分野の現在レベルに対応した問題を出題
- 旧版の共通レベルは、初回だけ各分野へ自動で引き継ぎ
- セッションごとに問題を並び替え、前回と同じ問題から始まらないよう調整
- 6コースすべて、正誤と答え合わせを残し、「次へ」を押してから進行
- 正解時は大きな緑色のチェック付き表示で、全コース共通に見分けやすく案内
- 学習中の「やめる」から、今回分をノーカウントにして終了
- 学習中の「やめる」をiPhoneでも押しやすい46px以上の操作領域に調整
- 各コースの問題数を個別に設定（初期値は各10問）
- 3問または5問ごとに「続ける／終了する」を選択
- レベル、XP、名前、学習設定をブラウザ内に保存
- 「最新版に更新」を押しても、名前・レベル・XP・学習履歴は保持
- スマホ操作時に画面が拡大・移動しにくい安定表示
- お気に入り・ブラウザタブ・iPhoneホーム画面に専用の学習アプリアイコンを表示
- Webアプリマニフェスト対応で、ホーム画面追加時も「のびる」の名前と高解像度アイコンを使用
- iPhoneの下部ブラウザバーを避けて操作ボタンを表示
- 暗算の「こたえる」ボタンを画面下部へ固定
- 数字記憶は2問目以降、「次へ」の後に開始ボタンを挟まず横バーから自動開始
- フラッシュカードはカード部分だけを一定間隔で更新し、表示速度のばらつきとカクつきを軽減
- 漢字回答後の「この漢字の学習ポイント」を読みやすい大きさで表示
- 名前選択欄の直下に「この名前で学習する」ボタンを表示
- 名前・問題数・間隔を保存したらホームへ戻る
- ホームの最上段に「きょうのトレーニング」を表示
- `names.txt` の「みっくん」だけに年中向けの「みっくんメニュー」を表示
- みっくん専用メニューを「メカづくり」「矢印で移動」「お宝集め」「光った絵の記憶」のミニゲームへ刷新
- 「メカをつくろう」は、正解した実際の絵を同じ大きさの部品トレーへ追加
- みっくん用の問題文を、幼児が読み取りやすい大きな見出しで表示
- 「だんだんだんをうごかそう」は年少段階16マス、次の段階から20マスの障害物マップ
- 上下左右の矢印を何度も押し、黄色い道を曲がりながらお宝まで6〜7マス進む移動ゲーム
- マップ開始時と移動後は、上下左右ボタン全体が画面内に見える位置へ必要な時だけ自動スクロール
- メカマップに安全な道と、岩・木・水などの障害物を表示し、違う方向を押してもやり直し可能
- お宝到着後は「つぎのミッションへ」が見える位置まで自動スクロール
- みっくん用は5問でメカ部品やお宝が集まり、正解時にメカが動く演出を表示
- みっくん用の不正解ではレベルを下げず、正しい絵を見せて次のミッションへ進行
- フラッシュカードは回答後、正しい順番と結果が見える位置まで自動スクロール
- フラッシュカードの誤答後は「あなたが入れた順番」と「正しい順番」を上下2段で比較表示
- フラッシュカードの答え合わせは最大7枚でもiPhoneの横幅内に収まり、絵を省略せず表示
- フラッシュ暗算の誤答後は、実際に出題された数字を足し算の形で再表示
- フラッシュ暗算は最初の回答で正誤を確定し、誤答後の再回答はせず「次へ」で進行
- 学習中の「やめる」をiPhoneの時刻・ステータス表示より下へ配置
- ホームの「学年別漢字一覧」から、小学1〜6年の配当漢字と中学1〜3年目安を切り替えて表示
- みっくんメニューは、「あんぱんのヒーロー」と「だんだんだん」を題材にした4コースを各5問
- みっくん専用の絵を16種類、専用問題を4コース各16問（合計64問）用意
- みっくんメニューでは、以前の動物・果物問題を混ぜず、専用の冒険問題だけを出題
- みっくんメニューは文字を読めなくても絵で遊べ、5問の星集めで進行
- 通常フラッシュカードとみっくんメニューに、統一した絵本タッチの絵カードを表示
- 操作・開始・正解・不正解・レベルアップの5種類の学習サウンドを再生
- 暗算は1回の回答で正誤を確定し、結果確認後の「次へ」で進行
- フラッシュ暗算は結果確認後に「次へ」を押すと、次の問題を横バーから開始
- フラッシュ暗算の「もう一度見る」は1回までで、その後は「降参する」に変更
- 誤答時は分野ごとにXPを4〜6%だけ下げ、必要な時だけレベルも1段階調整
- 既存のLv.1〜100はそのまま残し、Lv.101〜110を大学レベル、Lv.111〜120を天才レベルとして追加
- 分野別開始レベルは、学年目安12段階・−と＋・横バーで1〜120から選択
- iPhoneでは最初のタップで音声を開始し、操作音を聞き取りやすく調整
- 設定画面で5種類の学習サウンドを個別に確認可能
- フラッシュカードは、順番に表示された絵を覚えて4択で回答
- 数字記憶は、右から左へ流れた数字を同じ順番で入力
- 記憶コースは、レベルが上がるほど枚数・桁数が増え、表示も速くなる
- 回答候補の文字を大きくし、「び／ぴ」などの濁点・半濁点を見分けやすく表示
- 数字記憶の回答欄は画面幅に合わせ、長い数字も枠内へ収まるよう自動調整
- 登録者ごとの最終学習日時を「みんなの6分野レベル」に表示し、Firebaseで端末間共有
- フラッシュカードは、表示されたすべてのカードを表示順に選んで回答
- フラッシュカードの出題中と回答候補では名前を隠し、絵そのものと順番を記憶
- 分野別レベル調整の「レベル調整を終える」を微調整欄の直下へ配置
- 漢字問題には「現在の学年で出題できる字数」を表示し、レベルアップによる広がりを確認可能
- 正解時だけ余韻のあるベル調の「ピンポーン」を再生
- 数字記憶の「こたえる」ボタンをiPhoneのSafari下部バーより上へ固定
- 5問・10問終了後の「ホームへ戻る」を成績のすぐ下へ移動し、Safari下部バーに隠れにくく調整
- 通常メニューは、数字記憶・フラッシュカード・フラッシュ暗算・暗算・漢字を読む・漢字を選ぶの順に表示
- みっくんメニューは、年少さんから年中さんまで4段階の冒険ステップで成長を表示
- 通常の絵カードは動物・海の生き物・果物・乗り物の合計32種類、みっくん用は別に16種類

## ファイル

- `index.html`：アプリを開くファイル
- `styles.css`：画面デザイン
- `app.js`：学習機能
- `question-data.js`：漢字・熟語・四字熟語の問題データ
- `kanji-curriculum-data.js`：小中学校の学年別漢字・読み・熟語データ
- `DATA_SOURCES.md`：学年別漢字・辞書・四字熟語データの出典と利用条件
- `assets/learning-card-atlas-v2.png`：フラッシュカードとみっくんメニューの余白付き絵
- `assets/learning-card-atlas-extra.png`：追加した動物・海の生き物・果物・乗り物の絵
- `names.txt`：選択できる名前（1行に1人）
- `version.json`：iPhoneに最新版を読み込ませるための更新番号
- `firebase-config.js`：Firebaseの接続設定
- `firebase-sync.js`：Firestoreとの同期機能
- `firestore.rules`：Firestoreへ設定する試用用ルール
- `FIREBASE_SETUP.md`：Firebaseの設定手順
- `UPDATE_GUIDE.md`：今回の更新をFirebase・GitHubへ反映する詳しい手順
- `.nojekyll`：GitHub Pages用設定

## パソコンで確認する

`index.html` をダブルクリックしてブラウザで開きます。

## GitHubへアップロードする

1. GitHubで新しいリポジトリを作成します。
2. このフォルダ内のファイルを、リポジトリの一番上へアップロードします。
3. GitHubの `Settings` → `Pages` を開きます。
4. `Build and deployment` の `Source` を `Deploy from a branch` にします。
5. `Branch` を `main`、フォルダを `/(root)` にして保存します。
6. 表示された `https://ユーザー名.github.io/リポジトリ名/` を開きます。

## iPhoneのキャッシュ対策

- アプリを開くたびに `version.json` をキャッシュなしで確認します。
- 新しい更新番号を検出すると、`app.js` と `styles.css` を最新版で読み込み直します。
- Safariで別の画面から戻った場合や、ホーム画面から再表示した場合も更新を確認します。
- 名前、レベル、XP、問題数などの保存データは削除しません。

アプリを変更して再アップロードするときは、`version.json` の `version` も新しい文字列へ変更してください。

## 名前を変更する

`names.txt` をメモ帳などで開き、1行に1人ずつ名前を入力し、UTF-8形式で保存します。
「くん」「さん」なども含め、入力した名前がそのまま画面に表示されます。
保存した `names.txt` をGitHubへアップロードし、設定画面の「名簿を再読み込み」を押すと選択肢へ反映されます。

`index.html` をダブルクリックして確認している場合、ブラウザの安全制限で `names.txt` を自動読込できません。
設定画面の「names.txtを選ぶ」を押して、編集したファイルを選択してください。一度読み込んだ名簿はブラウザ内に保存されます。

GitHub Pagesを開いたまま別画面へ移動し、戻ってきた場合も `names.txt` の更新を自動確認します。
名前ごとの6分野のレベルとXPは、その端末のブラウザ内に個別保存されます。

## Firebaseで別端末と共有する

Firebaseを設定すると、名前ごとの6分野のレベル・XP・連続日数を別端末と共有できます。
設定方法は `FIREBASE_SETUP.md` を参照してください。
未設定時やオフライン時は、これまでどおり端末内へ保存されます。

## 保存について

6分野のレベルとXPは、利用している端末のブラウザ内に保存されます。
Firebaseを設定した場合だけ、端末間共有のためFirestoreにも送信されます。

旧版の共通レベルが保存されている場合は、更新後の初回起動時に同じレベルとXPを各分野へコピーします。既に4分野版を利用している場合、新しい「フラッシュカード」と「数字記憶」はレベル1から始まり、設定画面から個別に開始レベルを調整できます。その後は、学習した分野だけが個別に上がります。
